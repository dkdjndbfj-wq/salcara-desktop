# Desktop probe runtime

The complete desktop build also distributes a standalone Node.js executable for
the read-only MCP probe. Its complete version-matched license and dependency
notices are included as `resources/NODE-LICENSE.txt`. The probe's own MIT license
is included at `resources/desktop-companion/LICENSE`. No Codex Desktop app-tools
source is copied into the probe.

## SQLite request ledger runtime

The local request ledger uses modernc.org/sqlite v1.39.1 (BSD-3-Clause), a pure Go SQLite driver from https://gitlab.com/cznic/sqlite. SQLite itself is public domain: https://sqlite.org/copyright.html. This independently implemented ledger does not copy Cockpit application code, records, schemas, default pricing, or UI.

The notices below cover the newly introduced runtime modules and the libc module's embedded Go/netdb portions. The exact versions are pinned in go.mod/go.sum.
