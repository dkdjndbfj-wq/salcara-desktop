## 本地 API 密钥复制窄修

独立复核新增一次性客户端 Key 的复制入口时，发现共用 `app.js` / `copyText` 降级路径有两项边界问题：旧浏览器复制命令抛错会留下 body 下的临时明文 textarea；命令返回 false 时仍提示复制成功。

修正仅涉及该共用函数：临时节点离屏、只读、`aria-hidden` 且不可 Tab 聚焦；不论追加、选择或复制在哪一步失败，均在 `finally` 清空值并移除节点。现代剪贴板不可用或拒绝时仍尝试降级；两种方式均失败则返回 false 并显示通用失败提示，不把异常内容或密钥写入通知。成功复制仍使用原有提示和交互，未改变界面样式或动效。用户主动复制后，系统剪贴板内容按系统策略保留，不声称能擦除操作系统剪贴板历史。

`node --test scripts/test-copy-text-ui.mjs`：7 条通过，覆盖现代成功、现代拒绝/缺失后降级成功、旧复制命令返回 false / 抛异常，以及 DOM 追加 / 选择失败。各分支检查临时节点和其值均被清除、通知不含测试密钥。`node --check internal/console/web/app.js` 与局部 diff 检查通过。全部使用合成值与内存 DOM，不访问用户剪贴板或真实凭据。
