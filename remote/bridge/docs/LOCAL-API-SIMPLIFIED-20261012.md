### 金额数据与边界

- `official_account_cost.go` 为两处账号列表统一装饰 `costEstimate`。`usedUSD` 是保留的本机请求按用户价表计算的 API 等值之和，不是账户总花费。价表默认空白；缺价、未报告用量、非最终流量不得制造金额。部分样本明确为 partial，真实 0 与未知 null 分开。
- `remainingUSD` 仅在同一身份、套餐、额度重置窗口内，两次新鲜的官方额度观测之间有至少 3 个完整计价的本机请求、额度使用率增加至少 1 个百分点、价表版本相同时学习。计算为「本地样本费用 ÷ 已消耗百分点 × 剩余百分点」，优先周窗口，否则主窗口。它是该样本工作负载的 API 等值预测，不是保证可用的美元余额；其他客户端、不同模型和官方计费权重会影响误差。不按 Pro / Plus / Business 名称填固定美元额度，不把 credits.balance 直接当美元。
- 估算不会额外发模型请求或后台调用额度 API，仅利用现有额度刷新。校准样本只保留在内存，重启重新学习；读卡片只扫描有界的本机内存记录，不同步读磁盘或网络。
- `AccountEpoch` 取实际执行凭据的代次并随记录保存。无代次旧记录、删除后重新导入、其他卡片的记录不借给新身份估值；Token 窗口仍按已保存 API 的匿名 ID 统计，当前显示名称 / 主机不是历史身份凭证。
- `BeginAccountUsage` 覆盖尚未结束、未入队的流。普通 HTTP / 图片直到最终 Observe 入队后才释放；WebSocket 每个实际 turn 独立记录，握手不当推理调用。方法、路径、升级头必须同时匹配真实 WebSocket 路由；普通 POST 伪升级头不允许提前释放活动记录。
- `FetchStartedAt` 使用本机实际额度查询开始时间（包括 401 刷新重试之前），不信任提供商同名字段。样本只取前次观测完成后、本次查询开始前已完整结束的请求；查询期间发生本机工作则暂不预测。
- 连续性代次与 `CoverageChangedAt` 在清空、过期淘汰、保留范围 / 价表变更和活动表溢出时失效；更改关联卡片范围后须新的额度查询严格晚于检测时间。迟到旧额度、清空前的缓存、身份替换、未保存 / 丢失记录均不能重建虚假完整样本。活动表最多 `MaxRecords` 个键，极端并发溢出显式标为不完整，不无限增长。

- API 页面服务卡及服务窗口均提供 Codex、Codex CLI、Claude Desktop、Claude Code 入口，沿用原工具切换/备份流程。打开前读取配置快照和模型目录，最终写入时再次验证来源；失败时回滚原工具配置并撤销本次运行授权。启动结果不明时不自动重复重启。
- 首次选择账号后点“加入服务”，后端 `onlyIfEmpty + suppressKey` 原子创建默认本机客户端，不返回或展示随机手工密钥。日常启动用单独的工具专属、进程内授权；不轮换旧客户端的手工 Key，不清空已有账号池/别名/并发限制。手工复制接口、密钥重置、额外客户端放在高级设置。
- 本机启动地址限定 `127.0.0.1` 与具体工具路径，授权绑定客户端和服务代次；停用、删除、轮换、成员策略变化或 Bridge 重启后，旧授权失效。托管客户端不是普通账号，不能冒充单个 API 来源通过远程站点验证。此功能没有把本地账号池默认授权为远程源。
- 已在执行的本地请求会阻止切换；切换期间仅允许本次已提交授权的应用读取/发起请求，不取消已有工作。远程命令使用现有任务配置锁保护；桌面原生仍使用既有任务状态检查及结束任务确认。
- Codex 走 Responses，Claude 走 Messages，复用已有协议翻译/账号池；Claude Desktop 的兼容显示名先解析回客户端模型，再执行命名空间、别名及权限检查。手工 API 客户端亦可使用 `/v1/messages` 和 `/v1/messages/count_tokens`，仍受同一鉴权/并发/模型限制。
- 卡片统计仅包含当前启用客户端可路由的显式成员；文字固定成员、图片开关、重复凭据、失效成员均单独处理。不将账号库里未加入的账号计算进去。官方套餐与额度来自已有查询缓存；普通上游 API 无可验证数据时显示未验证，不把配置成功当作额度可用。
- 相同套餐细分、相同限额窗口显示各账号剩余额度范围，可以展开看单个账号。百分比不能相加成一个余额，也不据套餐名虚构美元总额。汇总读取不发推理/额度网络请求；缓存过期仅更新本机显示。
- 卡片打开工具前刷新实际参与文字路由的成员目录，固定成员模式不会查询未选中的成员。普通 API 复用原启动链路的只读 `/models` 检查；用户手工编辑的目录保留，不支持目录接口时沿用保存的目录，401/403 或成功返回空目录会阻止启动。官方账号每次读取原生 Codex picker 提示，不向官方凭据发送普通 API 目录请求。目录不代表账号对每个模型都有权限；原生 Codex/Claude、真实套餐及 Windows 安装包仍需实机验收，本轮仅使用 synthetic 数据和注入的启动器，不启动实际应用、不读真实凭据、不调用付费模型。
- 目录刷新使用事务内来源校验及 `Store.UpdateWithSnapshot` 的同次提交快照。清理失效默认模型导致的合法客户端代次变动可以继续本次预览；其他窗口在读取期间撤销/重建客户端、改成员、切换工具或账号则拒绝旧预览。最终启动仍核对预览 revision，不能把后到的配置更改当成自己这次目录更新。

## 界面与保存语义

- 服务弹窗日常展示启停、接口地址、密钥行。已有密钥只显示名称和固定遮罩，不假装能重新读取或复制原文；重置前明确确认旧密钥失效。
- 没有客户端时，先选择可调用 API / 账号，再点击“生成密钥”，固定名称“本机客户端”。打开页面、启用服务和展开高级设置均不创建密钥。
- 首建会重新检查当前账号和客户端列表，并向创建接口传 `onlyIfEmpty: true`；配套后端在持久化事务内拒绝重复首建。多窗口也不能各自创建一把“首个”密钥。
- 现有客户端不自动覆盖或新增。额外密钥、编辑、撤销及全局图片、网络、就绪检查放在默认收起的“高级设置”内。
- 密钥编辑只在外层展示名称、绑定账号、保存/重置。账号池、状态、并发、模型允许/拒绝规则、命名空间和别名折叠，但字段仍完整渲染和读取，未展开保存不会清空原值。
- 保存池成员顺序不依赖密钥库展示排序；缺失绑定不自动选择第一个账号，已移除的显式池成员/固定成员保留提示，不悄悄删掉或更换。
- 主页面服务卡的统计指标与 Agent 页面布局保持不变。未改变普通手机 UI、动画、反代协议或模型执行逻辑。

## 请求与并发边界

- 简版、编辑页的重置均仅发送 `POST /api/local/codex-api/clients/rotate {id}`，不通过全量保存夹带旧账号池或模型权限。后端仅轮换 Key 摘要，保留其他客户端字段。
- 同一控制台的创建/保存/重置/撤销共用写锁；使用弹窗 epoch、对象及 DOM 所有者校验，迟到回复不能写入另一弹窗。
- 创建和重置 POST 结果不明确时，本弹窗不能自动再发一次。用户重新打开核对后才能再次操作，避免再次使刚生成的 Key 失效。
- 一次性 Key 直接进入专用密钥弹窗，不等待后续列表 GET；关闭或换弹窗后不展示迟到 Key。明文不进入 HTML 属性、数据集或持久化配置，复用已有关闭时清理逻辑。
- `#apiServiceContent` 保留为服务整体；网络、图片、就绪模块挂载到专属 `#apiServiceAdvanced`。客户端编辑没有此槽，不会重复加载全局设置。网络保存仍更新服务主状态。
