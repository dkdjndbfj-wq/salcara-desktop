# 持久侧边提问

2026-10-15，本批实现仍待三端统一冻结和新产物验收；此前 acceptance APK/exe 不包含本批代码。

## 行为与协议

手机以同一聊天页内的可收起区域显示独立侧问。关闭页面、收起区域和应用重启都不应清除历史；只有明确删除才移除记录。新协议不设 20 分钟有效期或六轮限制。

Hub 能力 `session.side-question.persistent.v1` 对应四个命令：`open`、`read`、`send`、`delete`。手机生成 chainId；open 幂等地创建或读取独立记录。发送携带 operationId、expectedRevision、previousOperationId 和问题，read 接受数字历史游标。旧 catalog/ask 只用于旧客户端兼容，保留旧行为；新手机只启用持久协议。

Bridge 将记录保存于私有 StateDir/side-conversations/{codex,claude}。文件名绑定电脑、手机配对、agent、主会话和 chainId；原主会话上下文只取自 Bridge 已加载的主会话文本。持久身份还区分 API 账号、入口、凭据身份。进程重启、显示名或模型偏好变化不会删除历史；账号替换不能复用原记录发送上下文。保护账号的正常 token 刷新不改变身份，identity epoch 替换会阻止继承。

每次命令仍要求新的来源授权及运行时检查。持久历史和手机缓存不保存执行许可。配对撤销、账号切换、adapter 替换和响应返回时再次校验，避免旧授权恢复执行。

## 保存与并发

- operation 在网络调用前原子保存。相同 operationId 与相同输入返回已保存结果，不再调用模型；不同输入复用同一 ID 会被拒绝。
- 重启发现未完成 operation 时标记结果未确认，不自动重发。旧链仍可查看，用户可以另外新建侧问。
- 删除写入不含对话正文的 tombstone；在途回答返回后不能重建已删除的记录。
- 每页最多 50 轮，编码后不超过 1 MiB，游标覆盖实际返回的范围。单记录文件上限 32 MiB，保存失败明确报错，不删除旧记录，也不继续发送未保存的新问题。
- Windows 在临时文件创建前为存储目录设置当前用户和 SYSTEM 的私有继承 ACL；其它系统使用 0700 目录、0600 文件。

## 上下文边界

保存的完整历史与每次发送给模型的上下文分别处理。原主会话快照最多 80 条 / 64 KiB；独立请求总预算 96 KiB，回答最多 16 KiB，单次请求超时 40 秒。较早已确认侧问可从本次模型输入中省略，但不从保存的历史中删除。手机应显示是否发生截断。

侧问只通过当前固定账号的 Bridge 网关发送一次无工具请求，不操作主会话，不读取隐藏系统提示、图片、工具输出或其它子任务完整上下文。该行为不是原生完整上下文镜像。

## 当前验证

新增测试覆盖超过六轮、跨重启和旧时间戳保留、未知结果不重放、手机及账号隔离、在途删除、磁盘故障、编码膨胀分页完整性、Windows ACL，以及公共调度的服务端快照与新授权检查。Hub 将 read 视为瞬时读取，open/send/delete 保留持久幂等回执。定向普通与 race 结果由本批验收报告统一记录；没有真实账号或付费模型调用。
