# Salcara 桌面连接插件 v0.4.0（实验版）

> 历史技术资料，仅用于维护兼容实现；其中旧插件安装、授权和测试流程不是当前用户操作方法。普通用户请看 [最新使用教程](../../docs/USER-GUIDE.zh.md)，不要按本页安装旧实验组件。

提供只读诊断和明确授权后的原 Codex Desktop 会话读取、续聊。Bridge 可安装、卸载及撤回短期连接。不是 CLI 替代桌面，也不能仅靠安装就打开桌面发送能力。

实现已通过隔离的模拟宿主、私有本地网关及安装器测试，**尚未完成真实 Codex 插件 → Bridge → 服务器 → 手机的端到端验证**。私有桌面接口不是稳定公开 API；当前只接受研究过的 Windows x64 Codex 构建，更新后默认拒绝连接。

## 安装与授权

1. 使用包含本组件及独立 Node 运行时的完整 Bridge 软件包，在 Codex Desktop 卡片点击安装并确认配置备份。安装不需要模型 API，也不关闭或重启 Codex。
2. 保存原任务后自行重启原 Codex。旧版按 Bridge 提示卸载后安装；不会覆盖未知或改过的配置。安装同时添加同步 `PermissionRequest` 命令 hook；必须在原 Codex 中明确启用并信任这个具体定义，安装器不代替用户信任，不改全局授权。
3. 在一个独立的控制对话中，要求 Codex 列出本机已有会话，选择允许手机读取和续聊的原会话。使用真实会话 ID，排除当前控制对话。
4. 明确批准调用 `salcara_desktop_connect`，参数为 `allowRemoteControl:true`、`durationSeconds:600`、`sessionKeys:["codex:<真实会话 UUID>"]`。最多 200 个会话、30 秒至 30 天。向原会话发送任务可能触发该 Agent 的代码修改和命令执行；这不是只读授权。
5. 控制调用在授权期间保持执行，最终结果在撤回或到期时才返回。手机选择 Codex Desktop 并确认当前 API 后，只能打开和续聊授权的原会话；没有另起 CLI 或新用户目录。

本地授权不要求手机一直联网。它只监听电脑的 `127.0.0.1`，不会自行连服务器、持续上传会话或产生远程轮询。网络中断、退出手机、撤回授权或授权到期不停止已经交给原 Codex 的任务。恢复网络后按需读取原会话；发送回执不是助手已经回答。

安装、API 选择和 Hub 在线均不是桌面授权。连接失败只返回脱敏固定错误码，不能提供 Key、配置、私有描述文件、管道路径或调用身份来“修复”。未知版本、缺少真实宿主元数据或原生工具拒绝时，能力保持关闭。

## 支持与限制

- `salcara_desktop_probe` 默认仅检查继承环境；显式 `allowCatalogProbe:true` 才做版本检查和一次只读工具目录请求。该诊断工具始终报告 `desktopControl:false`、`remoteSend:false`。
- `salcara_desktop_connect` 使用当前获批 MCP 调用的真实 `_meta` 线程和轮次；不接受命令行、参数或环境伪造 caller。控制对话不能作为目标。
- 只允许原生 `list_threads`、`read_thread`、`send_message_to_thread`。列表按真实置顶/最近顺序，仅返回授权范围；宿主最多 50 条非置顶记录，置顶列表独立返回。历史每页最多 10 轮，可按需加载更早页；opaque cursor 绑定原会话与当前授权，不可跨会话或重新授权复用。输出有上限，不把截掉的记录说成完整历史。
- 手机能展示原生实际返回的回复、可见思考摘要、文件改动、命令和子 Agent 活动，不推断隐藏思考或未返回信息。
- 可信同步 `PermissionRequest` hook 可把授权范围内的真实审批送到手机，只允许本次允许/拒绝；不支持“本会话全部允许”、修改输入、永久权限或手机代答原生提问。最多 4 个待决请求，约 110 秒超时、撤回或手机无法回答时输出无决定，继续原 Codex 的正常审批流程，不自动批准，也不强制拒绝真实任务。
- 不提供桌面新建会话、停止任务、API 切换/重启、Claude Desktop 原生发送或任意 UI 自动化。Claude Chat/Cowork 的独立只读历史由 Bridge 提供，不由本插件控制。
- 状态明确提供 `capabilities`：`list/read/send` 可用；`approval` 仅在真实 scoped hook 请求已经到达后、同时带 `codex-hook-v1` 来源证明才开放；`interrupt/attachments/modelOverride` 仍不可用。旧插件缺少能力元数据时默认关闭这些操作，不靠界面标记猜测。Claude Desktop 的 Code 会话后台续聊由 Bridge 的独立 Claude Code 链路提供，不是原生 Chat/Cowork 控制。
- `session.send` 必须明确选择执行端：`controlSurface:"desktop"` 严格校验桌面授权，授权失效、图片或模型/推理覆盖不支持时直接拒绝；`controlSurface:"cli"` 只走后台。不会因本次连接状态而悄悄更换执行端。
- 发送操作 UUID 在当前授权内去重，重复请求不再次触发原生发送；回执丢失或发送超时按“可能已接收”处理，不自动作为新任务重发。内存只保留在飞请求；整个授权期间的精简磁盘记录仅包含内容指纹与结果 UUID，不包含原文、密钥或完整宿主结果，没有累计 128 条消息上限。记录随授权正常结束清理；异常进程退出可能留下精简记录，不被下次授权继承。跨授权重连仍需 Bridge/Hub 的稳定回执约束，不能把旧任务当新消息重发。
- 真实返回的子任务 UUID 只有已经在授权范围内才生成可打开链接，不从任务描述或路径推断会话，也不自动扩大授权。

## 安全与卸载

私有网关使用随机令牌、固定环回 Host、POST JSON、无浏览器 Origin，并限制请求大小、并发和持续时间。令牌只写入安装器私有资源目录的 `active-desktop.json`；Windows 在写入前建立当前用户和 SYSTEM 的受保护 ACL。令牌不进入手机、Hub、工具结果或日志。

撤回、MCP 取消、宿主输入关闭、进程退出或到期关闭网关，不关闭 Codex、不终止原任务。Windows 重新授权时，只可在进程共享锁下清除已到期、结构正确且 ACL/所有者匹配的私有租约；存活租约、外来文件和重定向文件始终保留，不根据 PID 判断是否安全。

卸载会备份当前配置，只移除本安装器拥有且未经编辑的 MCP 与 hook 块；保留其他配置、聊天、项目、备份、缓存资源和归档记录。配置归属不明确时停止自动卸载。卸载记录移除后 Bridge 立即拒绝使用仍留在本地的连接描述文件；已加载插件进程需在原 Codex 中取消工具调用或保存任务后重启才能退出。

安装使用原 CODEX_HOME，并启用逐工具 `prompt` 授权，不创建按 Key 分开的用户空间。绝对运行时路径要求保留完整软件包原位置。

## 开发

Node >=20，零外部依赖：`npm test`；入口 `node src/index.mjs`。所有自动测试使用隔离临时目录和模拟原生接口，不能当作真实桌面控制成功的证据。

安装器及本地适配在 `remote/bridge/internal/desktopcompanion`。本组件为独立原创 MIT 实现，不复制内置 Codex app-tools 代码。[OpenAI MCP 服务器文档](https://developers.openai.com/plugins/build/mcp-server)。
