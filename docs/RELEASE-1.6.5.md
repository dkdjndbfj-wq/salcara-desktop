# Salcara Desktop 1.6.5

本版本配套 Salcara Android 1.8.3 与 Salcara Hub 0.5.3，完善远程多 Agent、API 管理及桌面更新。

桌面更新流程：复用首页小球，显示下载进度、大小和速度，自动下载、校验、等待任务结束、安装并重启。需要兼容性升级时，禁止新任务，保留正在执行的任务、审批、停止及历史查看。

- 下载连接超时后有限次重试，支持带强 ETag 的断点续传和签名清单内的 HTTPS 备用地址。
- 重启后复用下载缓存并重新校验、解压；安装前检查磁盘空间。
- 新版本启动失败后回退，持久记录失败版本，避免反复自动升级；可以显式手动重试。
- Windows 更新 helper 保留独立恢复文件；启用当前用户的单次登录恢复，处理中途断电或进程退出。健康启动前保留旧版本备份。
- 支持单独签名的分批发布、暂停和版本撤回控制，支持复制不含任务、密钥及设备标识的更新诊断。
- GitHub 发布继续强制使用 Ed25519 更新签名。Windows Authenticode 为可选构建项。
- DeepSeek Harness 与 Hermes Agent 使用各自官方图标，桌面 Agent 卡片和 API 启动入口保持一致。

1.6.4 及更早版本需先通过现有普通更新或安装包升级到本版本。Hub 的最低桌面版本应在迁移验证后才启用；新版 Hub 可在服务端阻止旧客户端发起新任务，同时保留已有任务的事件和控制通道。完整发布和恢复说明见 [自动更新](AUTO-UPDATE.md)。

## 远程 Agent 与 API 管理

- 接入 Codex、Claude、DeepSeek Harness、Hermes，按 Agent 的能力提供启动、API 选择、权限和远程工作区。打开 Agent 直接启动；历史从设置中的对话记录进入。
- API 切换、配置恢复与手机任务共用准入保护，运行中或退出未确认时保留原进程与历史；修复 Windows 进程停止与空闲会话恢复。
- API 卡片支持固定凭据的流式测试、模型选择、耗时与实际 Token；测试遵守共享并发额度，但错误模型等测试结果不再污染正式任务的路由健康。取消测试不会取消其他会话。
- 配套 Hub 用户与来源授权，完善手机配对、恢复状态、持久事件、终端/文件/审阅及临时工具同步。

## 能力与验收边界

Hermes 会话固定启动时的 API/key/root/model，切换来源后通常需要新建；旧记录保留。DeepSeek 异常运行重启后保守锁定，需在电脑核查。DeepSeek/Hermes 的 Bridge 视图目前最多最近 400 个事件。Claude 的执行归属为进程内状态，Bridge 重启后不会自动接管旧会话；Claude Desktop Chat/Cowork 仍只读。

发布使用当前最终源码重新构建。既有真实 CLI + 合成上游回归不等于正式收费服务、实体手机和公网端到端验收。Windows 包使用原有 Ed25519 更新签名，本次未配置 Windows Authenticode 证书；macOS/Linux 桌面安装包和 iOS 签名发行不在此次交付范围。
