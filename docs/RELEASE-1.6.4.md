# Salcara Desktop 1.6.4

本版本保留原有界面、颜色和动画，重点修复远程编程内核：A 中转站离线时通过已配对的 B 站点完成受限切换、会话历史按消息分页、长 transcript 尾部读取预算、单实例恢复和本机工具发现。

更新检查每 2 小时执行；提示和下载不会终止正在运行的任务。Windows 安装器会保留配置、API 密钥库、配对记录和本地会话。

原生 Codex 发送仍需要 Codex Desktop 明确授权 lease；Claude Desktop 原生 Chat/Cowork 没有公开的外部发送接口，未将只读历史冒充成桌面控制。公网双 Hub、Android 真机和弱网验收应按维护记录单独完成。
