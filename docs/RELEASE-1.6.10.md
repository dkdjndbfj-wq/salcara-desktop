# Salcara Desktop 1.6.10

本版本配套 Salcara Android 1.8.7 与 Salcara Hub 0.5.7，修复时间不一致时远程连接提示不准确，以及导航栏“设置”换行溢出的问题。

- **准确提示时间异常。** 电脑与中转站的签名时间不一致时，显示检查系统日期、时间和时区的指引，不再只显示普通连接失败或引导重新登记。诊断仅来自已验签的信息，不会绕过身份、入口或随机挑战检查；陈旧缓存、坏签名和单纯网络延迟不会被当作可信校时依据。
- **区分未发送与结果未知。** 登记尚未发送时，同时保留未发送状态和校时指引；已经发出但结果未知的操作仍要求先核对原结果，不自动重复提交。刷新状态不重新登记、不修改 API，也不先读取聊天列表。
- **保留连接与历史。** 校时提示不会更换身份、重置配对或覆盖 API 配置。已保存连接校时后可重连；尚未保存的新连接明确提示再次验证。校时回拨后的新检查不会被旧的未来时间记录挡住，迟到请求也不能清掉新连接的校时诊断。切换目标后的旧错误不会污染当前连接或直连状态。
- **导航保持紧凑。** 十个入口保持单行排列，窄窗口可横向滚动到“设置”，避免入口挤入内容区域；保留键盘焦点提示和按钮触控高度。

本版本不会自动修改操作系统时间，不信任 HTTP Date 自动校时，也不放宽身份验证的有效时间窗口。若电脑时间已正确而仍有时间异常提示，请检查中转站时间或联系管理员。

“打开 Agent”仍直接启动 Agent，不预先扫描会话。已有配置和聊天记录不因本次更新、校时提示或 API 切换而删除；继续原会话仍取决于对应 Agent 的能力与原会话来源约束。

保持既有最低兼容版本和发布签名身份。Windows 更新包继续使用原 Ed25519 签名，未配置 Windows Authenticode 证书。合成回归、隔离浏览器检查和构建验证不代表所有真实手机、网络和付费 Agent 场景均已验收。
