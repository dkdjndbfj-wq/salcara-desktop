# Salcara Desktop 1.6.6

本版本配套 Salcara Android 1.8.4 与 Salcara Hub 0.5.4，让选择 API、打开 Agent 和手机远程使用更直接，同时改善最近会话与连续回复的交互。

- **打开 Agent 直接启动。** 不先加载或选择会话；对话记录保留独立入口。Codex、Codex CLI、Claude Code、Claude Desktop、DeepSeek Harness 和 Hermes Agent 使用紧凑的工具卡片。
- **更换 API 时先停止受管任务。** API 选择提供“仅应用”和“应用并打开”，移除任务结束勾选与重复确认。面板显示停止、应用、打开进度，执行期间防止重复提交；停止失败或结果无法确认时显示原因并中止后续变更。
- **保留现有聊天、项目和文件。** 切换 API 不覆盖旧记录。Hermes 旧会话保留原 API 身份，使用另一 API 需新建会话；其他 Agent 的继续能力遵循各自原生会话协议。
- **完善手机远程连接。** 区分电脑授权、手机配对与模型 API 凭据，改善自定义 Hub 地址、身份校验、来源切换和延迟响应处理。
- **项目选择更灵活。** 配合新版手机 App，可浏览电脑本地磁盘目录、创建项目，或选择“不关联文件夹”进入 Code/Work 会话。独立工作区及启动回执持久保存，重复请求不会自动启动第二个任务。浏览不授予 Agent 整盘权限，新建项目只授权精确目录。
- **重新整理本地 API 管理。** 管理面板分为“已加入 API”“连接工具”“高级设置”。从 API 卡片直接加入当前来源，已有多份独立接入配置时再选择目的配置。加入来源不自动启动服务。
- **补充多协议接入。** 提供 OpenAI Chat/Responses、Anthropic、Gemini 和 Ollama 连接示例，分别展示地址、模型与接入密钥；Gemini、Ollama 支持所列推理接口。
- **最近记录与流式回复更稳定。** 最近会话独立读取，刷新失败保留已有记录；连续回复保留输入焦点、草稿、工具展开和滚动状态。DeepSeek 可从原生记录分页读取较早消息，不再仅依赖最近 400 个事件缓存。

自动停止仅能处理 Salcara 可确认归属和状态的任务。外部启动且归属不明的进程、Hermes 共享 Gateway 的其他任务、重启后仍无法确认的 worker，可能需要先在电脑原工具中处理。Windows 原生 CLI 进程树管理不会自动扩展为其他平台同等能力。原生会话恢复、历史格式和读取大小仍受各 Agent 能力限制。

本次保持现有最低兼容门槛。Windows 自动更新包继续使用已有 Ed25519 签名；本次未配置 Windows Authenticode 代码签名证书。
