源：`remote/bridge`、`remote/desktop-companion`。与最新 Claude 隔离副本的运行源码一致；只有桌面开源 README / 旧 build.sh 的历史整理差异。此次仅修改更新内核、更新退出接口、版本、发布脚本、测试、CI 和文档。所有 HTML、CSS、web JS、图标、动画、文案保持原样；未修改其他 Agent 功能，未修改真实配置，不启动/重启真实 Codex 或 Claude。

版本：1.6.0，数字版本升级避开既有 `1.5.1-test.2` 比较器行为。发布仓库：`dkdjndbfj-wq/salcara-desktop`。不发布个人 Hub。

## 自动更新修复

- 签名清单增加 `schema: 1`、`product: salcara-desktop`、发布仓库身份。固定同仓库、同标签、精确文件名下载地址；错误后清除旧下载授权。
- 小清单流式读取真实上限，压缩包独占私有文件流式写入，大小和 SHA-256 验证。
- 取消信号覆盖下载、解压前验证、解压子进程和 ready 发布之前；验证期间取消也会清理暂存，不再误进入可安装状态。
- 全量 USTAR 检查在解压前拒绝路径穿越、绝对路径、Windows ADS / 保留设备名、链接、设备、PAX/GNU 覆盖、大小异常、重复路径、解压炸弹。发布端也运行同一检查。
- 安装标记验证确认完整应用目录和目标版本；不能识别的散装程序或不可写目录只能手动下载。
- 更新准备 / 提交 / 取消 API 使用既有 cookie + 同源 + JSON 鉴权，验证核心 PID / 版本。与新任务发送共用锁；当前任务、审批、子任务、已连接原生桌面任务未完成或请求仍在处理时拒绝退出。prepare 先冻结入口，不退出；helper 与签名状态 / 许可文件准备好后 commit 才安全退出。任何 commit 前失败调用 cancel 恢复入口，废弃 prepare 30 秒后自动过期，不会永久卡住。附着的非自有核心不被结束。未知活动适配器拒绝更新，不启动工具来检查。
- helper 成功启动后才准备退出；未收到安装许可、旧程序未退出时不交换文件夹。
- Windows helper 固定完整路径、隐藏窗口，运行时限制替换 / 删除范围；健康启动随机令牌确认后才清理旧副本。启动即失败时恢复旧目录；新进程仍活着但未确认时不强杀，保留备份待恢复。
- 自动清理不再扫描/删除任意 sibling 旧目录，不会提前删除回滚目录。安装失败使用原有错误/重试状态，没有设计新界面。

## 签名身份和构建

已有 package repo / 公钥为空，仓库外默认旧身份不存在，故本次新建独立桌面 Ed25519 身份，不覆盖任何已有身份。私钥只保存在用户目录下 `.salcara/signing/desktop/update-signing-key.pem`，写入前设置仅当前 Windows 用户继承的受保护 ACL；私钥不打印、不提交。公开公钥写入 package.json。它不是 Windows 代码签名证书。

GitHub 手动 workflow `desktop-release.yml` 使用 Windows runner，完整 Bridge + Electron + stdio Node + companion + 图标/文档/许可证打包，生成签名 tar、manifest、sig、首次下载 ZIP、SHA256SUMS。Secret 名 `SALCARA_DESKTOP_UPDATE_PRIVATE_KEY`，只在签名步骤导入临时文件并最后删除。流程不自动发布 Release，主任务检查后统一发布 v1.6.0，签名身份长期保留以供后续版本。Linux 原 source-check workflow 补跑 POSIX / race 测试。

发布打包额外补齐根 MIT 和实际 Go 工具链 runtime / 标准库许可证；不只附依赖名字/链接。官方 Node 许可证下载备用路径改用 .NET 下载，避免 Windows PowerShell 5 继承 PowerShell 7 模块路径时无法加载模块。
