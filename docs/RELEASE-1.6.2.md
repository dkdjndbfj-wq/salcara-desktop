# Salcara Desktop 1.6.2

本次为 Windows x64 稳定版修复更新，保留原有界面、视觉设计和动效。

- 修复最小化和关闭按钮的事件处理与拖拽区域冲突。
- 项目目录浏览使用 Windows 原生文件夹选择器。
- 减少工具检测的重复扫描和请求等待，修复动画循环重复启动。
- 改善扫码配对反馈、多中转站绑定及条件解绑。
- 修复事件重试、重连授权窗口和迟到回执相关的远程进度问题。
- 通知只在 Codex 中文最终回答的真实回合结束后触发，并去重。
- 支持已配对站点之间的 API 与 Hub 安全交接，保留原会话。

建议配合手机 1.8.1 和 Hub 0.5.1 使用。沿用既有更新公钥、配置和会话目录，不需要卸载旧版。Windows 安装包没有 Authenticode 证书；客户端更新使用已有 Ed25519 签名验证。

远程切站要求目标 Hub 已保存并配对，任务运行或仍有待确认内容时不切换。当前站点在交接前彻底不可达时，尚不支持独立备用通道切站。Codex 原生桌面能力依赖有效授权；Claude Desktop 原生 Chat/Cowork 仍不能当作完整远程控制。
