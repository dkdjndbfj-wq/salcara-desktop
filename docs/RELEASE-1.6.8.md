# Salcara Desktop 1.6.8

本版本配套 Salcara Android 1.8.5 与 Salcara Hub 0.5.5，完善手机远程的连接切换、API 设置入口及 Bot 恢复链路。

- **在连接状态中切换方式与目标。** 右侧集中选择中转站、Bot 或直连，以及已保存的具体中转站或 Bot 组。选择只是待切换草稿，确认后才启用；当前连接以电脑返回的状态为准。切换时保留其他连接配置，刷新不会覆盖待切换选择。
- **手机远程页面更紧凑。** 移除重复的大标题、说明和左侧方式页签，保留返回、关闭及配置入口；常用状态与手机绑定集中显示，高级维护默认折叠。
- **补回远程 Agent API 设置。** 展开后可查看 Codex、Claude Code、DeepSeek Harness 与 Hermes 的既有远程 API／模型设置，不读取会话列表。设置作用于当前生效的中转连接，而非尚未启用的选择；保留站点来源权限、活动任务和模型校验。增加目录授权、审批策略与 API 来源权限的导航入口。
- **从已有 API 接入。** 使用已加入的 API 获取中转站或 Bot 配置，区分模型 API 密钥、电脑授权及手机配对凭据；保留手工地址、独立登记码及登记结果检查／重试。
- **保持连接身份与撤销边界。** 重连、迁址和 Bot 配置导入核对原服务身份；取消或撤销后的迟到结果不能重新启用旧连接。Bot 保留组级绑定及原手机令牌，并处理首次回执丢失、设备暂时为空、重复请求和重启恢复。
- **改善运行与更新恢复。** DeepSeek Harness 启动和安装前核对 Node.js 版本；修复打包资源定位、受管核心进程监督和 Windows 文件权限处理。Windows 更新回退等待短暂文件占用释放，失败仍保留恢复材料，不覆盖原备份。

“打开 Agent”仍直接启动 Agent，不先加载或选择会话。切换 API 不删除已有聊天；继续原会话的能力取决于各 Agent 的原生协议。Hermes 旧会话保持原 API 身份，使用另一 API 需新建会话。无法确认归属或状态的外部任务仍可能需要在电脑原工具中处理。

Bot JSON 是连接与授权配置，不会替代实际在线的 Hub、Bridge 和 Agent。电脑需要保持运行，网络及对应 Agent 环境需要可用。DeepSeek Harness 的 npm 安装需要系统 Node.js 24.9 或更新版本。请求超时不等同于任务已经停止，请先确认原任务状态，避免重复执行。

保持现有最低兼容门槛及更新签名身份。Windows 自动更新包继续使用已有 Ed25519 签名；未配置 Windows Authenticode 代码签名证书。模拟布局和合成回归不等于真实手机、网络、Agent 或安装版的现场验收。
