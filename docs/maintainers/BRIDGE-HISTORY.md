## 避免继续沿用的旧流程

- 当时服务器要求 `salcara.hub.http.v1` 宿主扩展、`.s2plugin` 安装和信任发布者配置；当前使用独立 Docker Hub，不再安装或维护该服务器插件。
- 当时桌面实验使用 20 会话/10 分钟限时授权，Claude Desktop 自动配置曾因本地库不兼容而暂停。后续实现已变化，不能继续用旧表格判断当前支持范围。
- 旧工作台流程和 Key/子任务/提问缺口描述已被后续产品教程与实现替代，不应照旧稿改动手机界面。

## 继续有效的验证原则

只读取实际可见回复、工具公开信息和思考摘要；缺数据不虚构内部思考或完成状态。Hub 可达、工具安装、API 已选择与桌面授权是不同状态。未知回执不等于未执行，不能重新创建相同任务。

CLI 与原生桌面执行面保持区别，不因接口不可用静默切换。原生深链接处理成功只证明已请求导航，不证明窗口已刷新、消息已发送。跨进程续聊先结束原任务，不以另一个后端的 idle 状态证明所有原进程已停止。

没有端到端加密或永久 exactly-once 的承诺。配对、模型 Key、桌面本地租约和管理员身份彼此分离，不上传真实配置、宿主管道信息或私有凭据。

现行兼容组件与授权技术边界见 [组件 README](../../remote/desktop-companion/README.md)。该组件不是已删除的 Sub2API 插件。
