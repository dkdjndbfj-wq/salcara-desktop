| 场景 | 结果 |
| --- | --- |
| GitHub 已发布 1.6.4 → 本机构建 1.6.5 | 验证原始 1.6.4 签名及哈希后，使用旧版现有下载和安装入口完成升级；新版重启并确认健康。 |
| 1.6.5 → 夹具版本 1.6.6 | 自动下载、校验、进入 waiting；真实核心返回强制更新策略；忙碌标志存在期间未启动安装 helper；解除后自动安装、重启并确认新版健康。 |
| 目标版本启动立即失败 | 还原 1.6.5，重新打开后确认失败目标被隔离，重新检查没有自动再次安装。 |

忙碌条件由验收夹具模拟；实际任务准入及审批保留由 Go 测试单独覆盖，没有将模拟忙碌当作真实 AI 任务完成测试。登录恢复也以中断事务夹具验证，没有在用户系统中制造断电。

正式交付目录另外确认：使用真实发布仓库及原有公钥、入口为 `main.cjs`、没有 QA bootstrap，更新实现与本次源码一致。签名清单、USTAR 路径策略、大小、SHA-256、安装器 PE 及便携目录清单全部验证通过。
