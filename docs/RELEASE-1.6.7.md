# Salcara Desktop 1.6.7

本版本配套 Salcara Android 1.8.5 与 Salcara Hub 0.5.5，完善 API 接入、手机远程连接及 Bot 的恢复与撤销边界。

- **从 API 接入手机远程。** 使用已加入的 API 获取中转站或 Bot 配置，区分模型 API 密钥、电脑授权及手机配对凭据；尚未加入 API 时明确提示先完成 API 配置。
- **连接方式与状态更清楚。** 手机远程按中转站、Bot、直连显示当前方式所需的配置，集中显示连接状态和已绑定手机，高级设置默认折叠。
- **固定已信任的服务身份。** 重新连接、目录迁移和 Bot 配置导入继续核对原服务身份；取消或撤销后的迟到结果不能重新启用旧连接。
- **Bot 绑定与恢复更稳妥。** 配合新版 Hub 和手机 App，保留组级绑定及原手机令牌，处理首次绑定回执丢失、设备暂时为空、重复请求与重启恢复；邀请失效和手机权限失效分别处理。
- **撤销后停止旧请求。** 配合新版手机和 Hub，已撤销的连接不能因挂起请求、迟到回复或重启而恢复权限。
- **完善 Agent 启动环境检查。** DeepSeek Harness 启动和安装前核对 Node.js 版本；修复打包后资源定位、受管核心进程监督及 Windows 文件权限处理。
- **更新失败时更可靠地回退。** Windows 短暂占用新版程序目录时，回退会等待占用释放；等待期间保留新旧两份程序，超时仍保留恢复材料，不覆盖原备份。

“打开 Agent”仍直接启动 Agent，不先加载或选择会话。切换 API 不删除已有聊天；继续原会话的能力取决于各 Agent 的原生协议。Hermes 旧会话保持原 API 身份，使用另一 API 需新建会话。无法确认归属或状态的外部任务仍可能需要在电脑原工具中处理。

Bot JSON 是连接与授权配置，不会替代实际在线的 Hub、Bridge 和 Agent。电脑需要保持运行，网络及对应 Agent 环境需要可用。DeepSeek Harness 的 npm 安装需要系统 Node.js 24.9 或更新版本。请求超时不等同于任务已经停止，请先确认原任务状态，避免重复执行。

本次保持现有最低兼容门槛及更新签名身份。Windows 自动更新包继续使用已有 Ed25519 签名；未配置 Windows Authenticode 代码签名证书。安装包验证和合成 Agent 回归不替代真实手机与真实 Agent 的现场试用。
