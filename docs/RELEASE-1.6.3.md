# Salcara Desktop 1.6.3

Windows 安装与更新修复版，保留现有界面和动效。

- 修复更新缓存残留导致卸载后无法重装的问题，兼容 1.6.1 / 1.6.2 的残留目录。
- 修复 Windows 更新辅助程序未真正执行、或随旧程序退出而终止的问题；确认就绪后才安全退出。
- 更新检查改为每 2 小时一次。提示窗口和下载不停止任务，不自动安装；运行中的任务和待处理请求会阻止重启安装。
- 补齐更新弹窗的关闭处理，关闭弹窗不影响主窗口或 Agent 任务。
- 保留原更新公钥、API、配对和会话目录，不新增配置迁移。

1.6.1 / 1.6.2 用户若内置更新失败，请退出 Salcara 后手动运行 1.6.3 安装包，无需删除 AppData 或先卸载。已经卸载且留下更新缓存时，也可以直接运行新版安装包。不要反复尝试旧版内置更新。

更新采用既有 Ed25519 验证；Windows 安装包仍没有 Authenticode 证书。
